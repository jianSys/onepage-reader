LXGW WenKai / 霞鹜文楷 — Regular, converted to a 12pt CPFONT bitmap pack

What this file is
    LXGWWenKai-Regular_12.cpfont is a 2-bit e-ink glyph pack for the embedded
    simulator's virtual SD card, produced from the LXGW WenKai (霞鹜文楷) face by
    firmware/lib/EpdFont/scripts/fontconvert_sdcard.py. The CPFONT container carries
    no name table, so the attribution lives next to it instead of inside it.

License
    SIL Open Font License 1.1 — the license text is shipped alongside this file as
    OFL.txt. The web simulator serves the pack so the embedded firmware can render
    Chinese UI labels and Chinese book text; the same face ships preinstalled on
    OnePage device SD cards.
